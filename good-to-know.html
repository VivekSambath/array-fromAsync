Before you ship it

Errors

If any item or mapFn fails, the whole promise rejects. Wrap it in try / catch.

Infinite sources

An endless generator never finishes, so the promise never resolves.

Support

Chrome / Edge 121, Firefox 115, Safari 16.4, Node.js 22.
