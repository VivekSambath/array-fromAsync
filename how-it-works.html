How it works

One item at a time, in order

  1. 01

    Get the next item

  2. 02

    Wait for it

  3. 03

    Run mapFn and wait again

  4. 04

    Push it into the array

  5. 05

    Done? Return the array

It does not ask for item 2 until item 1 has finished.
