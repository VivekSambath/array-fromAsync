Read a file into an array of lines

The readline interface is an async iterable, so you can pass it straight in.

import fs from "node:fs";
import readline from "node:readline";

const rl = readline.createInterface({
  input: fs.createReadStream("todo.txt"),
});

const lines = await Array.fromAsync(rl);
// ["Buy milk", "Call mom", "Ship it"]
