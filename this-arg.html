What thisArg is for

When mapFn is a regular function that uses this, thisArg tells fromAsync what this should be.

Arrow functions ignore it, so most code never needs it.

Press Run to compare the call with thisArg and the call without it.
const pricing = {
  taxRate: 0.2,
  async addTax(price) {
    return price * (1 + this.taxRate);
  },
};

await Array.fromAsync([10, 20], pricing.addTax, pricing);
// [12, 24]: this = pricing
await Array.fromAsync([10, 20], pricing.addTax);
// [NaN, NaN]: this is lost
// arrow function: no thisArg needed
await Array.fromAsync([10, 20], (p) => pricing.addTax(p));
