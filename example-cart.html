Get product details for a cart

You have product IDs and need the full details for each one.

The async mapFn sends one request at a time, which goes easy on a rate-limited API.

const cartIds = [101, 102, 103];

const products = await Array.fromAsync(
  cartIds,
  async (id) => {
    const res = await fetch(`/api/products/${id}`);
    return res.json();
  },
);
// [{ id: 101, name: "Mug" }, …]
